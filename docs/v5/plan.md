# V5 Plan — 手动编辑镜头段 + 回存 blend

日期: 2026-08-18
状态: 进行中

## 关键决策（grill-me 结论）

### 编辑态交互

1. 编辑入口：顶栏右上角「编辑」按钮 → 全局编辑态
2. 编辑态界面：顶栏简化（放弃+标题+Save）、聊天收起、双视口保留、底部时间轴+多轨道
3. 两 pose 编辑：拖拽为主 + 侧栏数值微调（双向同步）
4. 预览帧定位：改起点→跳起点帧，改终点→跳终点帧
5. 约束编辑：拖拽目标点 + 侧栏数值微调
6. 朝向编辑形态：侧栏按段类型切换（线性→朝向角度；TRACK_TO→目标点）
7. 跟随模型：本期不做；target 有动画→判复杂 C（约束元数据记 `target_animated`）
8. 新增段：默认静止段（起点=终点=上一段终点），时长 3 秒可改，朝向继承上一段
9. Save 脏标记：有改动才亮
10. 删除交互：右键菜单 + 侧栏删除按钮
11. 删除不补位（留空档，空档相机静止）
12. 删除弹窗确认
13. C 段侧栏：只读 + 不可编辑提示 + 删除
14. 段颜色：蓝=S / 橙=C；选中深、未选中浅

### 回存与切换

- 回存路线：后端读原 blend → Blender 脚本改关键帧/约束 → 另存新 blend（无损）
- 保存策略：聊天源累积 + 版本号（`scene_vN.blend`）不覆盖；上传源扁平 `upload_output/<时间戳>.blend`，每次保存新文件成为新源
- 多 blend：后端扫描文件夹 + 前端下拉框（自动最新 + 手动切换）

## 实现顺序（高层切片）

- **T1** — 编辑态 UI 骨架（顶栏编辑按钮 + 编辑态布局 + 底部轨道 + 播放头）
- **T2** — 段的编辑（两 pose 编辑 + 约束编辑 + 侧栏）
- **T3** — 新增 / 删除段（新增静止段 + 删除不补位）
- **T4** — 回存 blend（后端 Blender 脚本 + API 端点）
- **T5** — 多 blend 切换（blend 列表 + 自动最新 + 手动切换）

## 依赖关系

```
T1 → T2 → T3 → T4 → T5
```

- T2/T3 依赖 T1（编辑态 UI 骨架）
- T4 依赖 T2/T3（编辑操作的定义：改 pose / 改 target / 删段 / 加段）
- T5 依赖 T4（版本化 blend 产物）

## 关键约束

- 编辑操作作用在 **blend 结构层次**（关键帧值 / 约束 target），不经过 glTF，保证无损
- 复杂段（C）不可编辑（只查看 + 删除）；S/C 判定沿用 V4 分通道口径（TRACK_TO 可重演归 S）
- 回存后需重新导出验证无损（编辑生效 + 其它段不变）
